# Context Sharing (A2A)

**Message Type:** Agent-to-Agent  
**Purpose:** Share context between agents  
**Version:** 1.0.0  
**Status:** To Be Developed

## Message Structure

*This message format is to be developed. It will handle sharing of context, specifications, and knowledge between agents.*

## Planned Fields

- `messageType`: "a2a.context-sharing"
- `contextType`: Type of context being shared
- `contextData`: The context data
- `relatedWorkItems`: Related work items
- `expirationTime`: When context expires

## Use Cases

- Sharing specification updates
- Sharing architectural decisions
- Sharing domain knowledge
- Sharing test results
