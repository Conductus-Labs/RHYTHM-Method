# Jira Integration Scripts

Setup scripts and configurations for integrating RHYTHM Method with Jira.

## Overview

These scripts help you set up RHYTHM Method workflows in Jira using:
- Jira Software (for work items and project management)
- Jira Automation (for workflow automation)
- Jira Service Management (for service-based workflows)

## Quick Start

1. Review the setup guide for your use case
2. Run the appropriate setup script
3. Configure your Jira project settings
4. Start using RHYTHM Method workflows

## Scripts

### Software Integration

- `setup-issue-types.sh` - Creates RHYTHM Method issue types
- `setup-workflow.sh` - Configures Jira workflow for RHYTHM Method
- `setup-board-config.sh` - Sets up board configuration for RHYTHM Method

### Automation Integration

- `setup-automation-rules/` - Jira Automation rules for RHYTHM Method
- `setup-webhooks.sh` - Configures webhooks for RHYTHM Method integration
