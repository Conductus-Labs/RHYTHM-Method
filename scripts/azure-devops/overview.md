# Azure DevOps Integration Scripts

Setup scripts and configurations for integrating RHYTHM Method with Azure DevOps.

## Overview

These scripts help you set up RHYTHM Method workflows in Azure DevOps using:
- Azure Boards (for work items and project management)
- Azure Pipelines (for automation)
- Azure Repos (for version control integration)

## Quick Start

1. Review the setup guide for your use case
2. Run the appropriate setup script
3. Configure your Azure DevOps project settings
4. Start using RHYTHM Method workflows

## Scripts

### Boards Integration

- `setup-work-item-types.sh` - Creates RHYTHM Method work item types
- `setup-board-columns.sh` - Configures board columns for RHYTHM Method
- `setup-queries.sh` - Creates RHYTHM Method queries (TEMPO, Flow, Control)

### Pipelines Integration

- `setup-pipeline-templates/` - Azure Pipeline templates for RHYTHM Method
- `setup-automation-rules.sh` - Configures automation rules for RHYTHM Method
