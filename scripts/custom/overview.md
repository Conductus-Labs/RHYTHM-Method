# Custom Integration Templates

Templates and guides for integrating RHYTHM Method with other project management tools.

## Overview

These templates provide a starting point for integrating RHYTHM Method with custom or less common project management tools.

## Available Templates

### API Templates

- `api-template-rest.md` - REST API integration template
- `api-template-graphql.md` - GraphQL API integration template
- `api-template-webhook.md` - Webhook integration template

### Integration Patterns

- `integration-patterns.md` - Common integration patterns for RHYTHM Method
- `custom-workflow-template.md` - Template for creating custom workflows
